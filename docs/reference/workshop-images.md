# Workshop illustrations

## Curation

The inline image loader in `build_with_claude_workshop.html` uses `data-art` keys and tries `assets/workshop/<key>-01.jpg`, then `<key>-02.jpg`. Keep filenames unchanged; delete the unwanted option and reload. On Vercel, deploy the deletion first. No build step or directory listing is needed. Both missing or undecodable restores the text fallback. Copy the assets folder alongside the HTML for offline use.

- `harness`: visual interlude after the tool-description/tool-call slide.
- `context-sources`: illustration replaces the six-way overview table visually; the table remains as fallback, and the following six slides hold the detail.
- `harness-location`: replaces the three location cards with a large infographic; distinguishes laptop sleep, hosted chat persistence and an always-on remote harness.
- `context-window`: new explainer immediately after “Everything is context engineering”, followed by the moved “Context rot” slide. Shows loaded inputs, attention, processing, next-token output and the append/repeat loop. Capacity is qualified by model; tokens are not words.
- `context-rot`: chart immediately after “One window in. One token out.” A conceptual decline, not benchmark data; no numeric thresholds. Original detailed explanation remains as fallback and in speaker notes.
- `skills-gym`: square gym satire alongside three practical pain → solution examples. Descriptions have overhead; full skill bodies load on trigger, rather than all installed skills loading in full.
- `context-map`: map/library metaphor for CLAUDE.md pointing to feature references, with history in git. Original three cards are the fallback.
- `development-loop`: analyze → improve → implement → review, with findings returning to the plan. Original detailed workflow is the fallback.

## Shared style

Wintercircus editorial diagram: graphite ground, warm cream geometry, circus-red emphasis, restrained ultramarine and magenta, crisp geometric type, subtle print grain, generous negative space.

Generated with the built-in image generation tool. JPEGs are approximately 16:9, except the square `skills-gym` pair. `object-fit: contain` preserves full diagrams; mobile uses natural image height and stacks the gym image above its examples. Deleted options need not be regenerated: curation is intentional.
